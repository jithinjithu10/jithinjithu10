## Projects

### Weighted Ensemble Model for Malware Classification & Detection
- Full pipeline for malware classification across 21 families using a Mixture-of-Experts (MoE) approach.
- Components: dataset preparation, image preprocessing (128×128), expert models trained per family/group, a sigmoid-based router for expert selection, weighted ensemble fusion, and a family-wise evaluation report (total, correct, wrong predictions).
- Emphasis on reproducibility, per-family metrics, and visualizations of each expert model.
